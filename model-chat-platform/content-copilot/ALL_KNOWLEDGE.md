# 01 品牌核心与长期资产

品牌：科大讯飞AI学习机。

长期传播核心不是“多做题”“多上课”，而是：
- AI个性化精准学
- 找准薄弱点再学
- 减少盲目看课、盲目刷题
- 帮孩子形成更高效、更自主的学习方式
- 将AI、教育教研与真实学习场景结合

高频品牌主张：
- 不报班 不刷题，就用科大讯飞AI学习机
- 告别盲目看课刷题
- AI个性化精准学
- AI全程导学精准学
- AI 1对1精准学
- 超拟人AI老师讲解
- 高端学习机领导者

长期能力资产：
- 科大讯飞长期深耕AI教育
- 星火教育大模型
- 自研AI能力与软硬件一体化
- 长期教育场景积累
- 国家科技进步奖一等奖等科技荣誉
- 全国大量中小学应用基础
- “国家队品牌”“自主可控”等信任资产

理想品牌气质：
大品牌感、有技术但不炫技、有教育理念但不空喊、有用户利益但不制造焦虑、有传播力但不过度承诺。

# 03 人群与需求

## 3-8岁
识字、拼音、数学思维、英语启蒙、幼小衔接、兴趣与习惯。

## 小学生
尤其五六年级：新课标、新教材、课本吃透、错因定位、学习方法、阅读、英语表达、数学思维、预习复习。

## 初中生
学习效率、备考、阅读理解、英语分级阅读、精准定位薄弱点、不盲目刷题。

## 3-18岁阅读
阅读是长期底层能力，语文英语均可建立分阶段阅读路径，不将阅读完全绑定于做题得分。

## 家长高频需求
- 不知道孩子哪里不会
- 刷很多题但效果不佳
- 辅导太累
- 报班成本高
- 学习规划不清
- 想提高效率
- 想让孩子更独立
- 关心护眼
- 关心设备能否长期用
- 关心是否同步新教材、新课标

高频价值：省时、省心、省钱、找得准、学得明白、少走弯路、学习更有路径。

# 04 传播主张与表达体系

优先结构：用户问题 → AI如何解决 → 用户得到什么。

避免：功能1 + 功能2 + 功能3 + 技术名词堆砌。

高频价值表达：
- 不盲目刷题
- 先找准，再学
- 学习更精准
- 减少无效时间
- 帮孩子建立自己的学习路径
- 不只会知识，也逐渐学会怎么学

“报班 / 刷题”表达：
- 可作为对比
- 不贬低正常教育服务
- 不制造家长焦虑
- 尽量说“盲目报班、盲目刷题”而非绝对否定

正确的“拔高”：
具体功能 → 学习方式变化 → 新课标能力要求 → AI时代教育变化 → 人才能力与社会价值。

不要直接跳到“科技改变未来”“为国家培养人才”等空泛口号。

# 05 渠道打法

## 电梯 / 户外
- 3秒可读
- 一个核心利益点
- 小学家长优先
- 文案与视觉都不能太复杂

## 公交车身 / 下沉市场
强调省钱、省心、省时间。可顺口押韵，但准确优先。

## 电商主图
要有明显电商感：立刻下单、立享优惠、马上可用、新学期行动感。避免虚假紧迫感与绝对承诺。

## 朋友圈
短、不折叠、员工/导购可直接转发、不像公关稿、一条突出一个主要点。

## 公众号
适合新课标解读、产品能力解释、科普、用户教育。开头避免新闻发布会感。

## 短视频
封面：单一钩子、具体、不晦涩。
发布文案：不重复封面，前两句说清价值。

## 高管访谈 / 媒体专访
现象/问题 → 企业判断 → 产品/技术实践 → 教育理念 → 行业/社会价值。

## 张泉灵信息流

## 教师节
祝福老师 + 一台学习机背后的教研力量；AI老师“晓悦老师”人格化；朋友圈兼顾“教师节快乐 + 教研实力藏不住”。

## 公益故事
渐冻症儿童米然：学习机作为入学礼物；传播温暖克制；封面应明确故事与渐冻症相关，不能只剩抽象金句。

## AIGC品牌创意：Hard模式
主题：为什么偏要选Hard模式 / 为什么偏偏是这条路。
内核：自主可控、做难而正确的事、教育/医疗/助听等高难度真实场景。
场景：会议纪要、智医助理、智能翻译、学习辅导、助听器。

## 开学季
讨论过：开学找节奏、学习机开学能力大考、闯关隐喻、找到自己的学习问题、新学期升级什么。“学习机开学第一课”更适合作为独立品牌向创意。

# 07 教育政策与内容框架

高频政策背景：
- 2022版义务教育课程标准：核心素养、跨学科、情境学习、做中学/用中学/创中学
- 《基础教育课程教学改革深化行动方案》（2023）：主题式学习、项目式学习、教学方式转变
- 《教育强国建设规划纲要（2024—2035年）》
- 基础教育“扩优提质”

新课标传播时，不只写专业词，尽量翻译成家长语言：
- 不只是把题做对，还要知道为什么
- 不只是记住知识，还要会用
- 英语不只是套句型，而要能在情境中表达
- 数学更重思维与解决问题
- 语文更重整本书阅读、表达与思辨

“五件事”框架：
1. 学懂课本
2. 找准错因
3. 想明白难题
4. 互动练能力
5. 做中学

# 08 合规与风险

总原则：有传播力，但不绝对化、不保证学习结果、不贬低同行、不制造过度教育焦虑。

高风险：
- 最好、唯一、100%、永远、一定提高等绝对化
- 保证提分、一定进步、用了就领先等效果承诺
- “别的学习机不行”“报班都是浪费钱”等竞品或行业贬低

更安全：
- 不盲目报班
- 不盲目刷题
- 减少无效学习

“高端学习机领导者”“连续五年双第一”等应以最新证明材料为准。

“不报班 不刷题”历史解释逻辑：
- 指向避免盲目、重复、低效学习
- 不否定合法合规教育服务
- 与减轻学生过重负担方向一致

# 09 用户判断偏好

用户最看重：
- 逻辑比辞藻重要
- 不为了改而改
- 要有明确判断
- 不希望一次给太多选项
- 喜欢先给最推荐版本
- 根本逻辑不对时可以直接推翻重写

高频反馈的真实含义：
“不对味” = 品牌感/传播目标/逻辑有问题；
“太官方” = 不像人说话，像新闻稿或PPT；
“太多了” = 信息优先级没做，不只是删字；
“不够具体” = 要落到场景、镜头、台词、功能发生方式；
“再拔高” = 建立产品→教育→社会价值逻辑链，不是堆宏大词。

偏好表达：
- 大品牌感
- 简洁
- 有力
- 肯定句优先
- 少问句
- 避免地推感
- 可适度押韵，但准确优先
- 朋友圈尽量不折叠
- 户外3秒可读

# 10 创意与视觉偏好

创意偏好：
- 有完整机制
- 有视觉隐喻
- 有人物行为
- 能落地拍摄或AIGC执行
- 一个创意最好能一句话说清

不喜欢：
- 只有“沉浸式”“打造共鸣”“年轻化”等空概念
- 真人拍摄成本高且无替代方案

视觉偏好：
- 爱死机式电影感
- 偏写实3D
- 未来感
- 概念化
- 有光影与色彩
- 不要破旧末世感
- 会议室不要像饭店
- 办公室要像真正未来办公室
- 电脑最好能看到正面

人物：
中国人、普通长相、不过度妆感、背景干净、可全身照。

色彩：蓝 / 绿 / 橙，避免过分粉嫩。
构图：可以更有张力，不必横平竖直。
